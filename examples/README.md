# Example data

This fictional DBROOT contains 16 songs across four albums, six favourites, three images, two e-books, and three root folders. It is intended for exploring the editor on your PC.

Open `examples/DBROOT` with **Browse DBROOT…**, or pass its path to `DBROOT.Editor.exe`. The paths are illustrative catalog entries; all artists and titles are fictional.

To reset the demo database, run from the repository folder:

```powershell
.\examples\Create-ExampleData.ps1
```

The script replaces the six demo database files in `examples/DBROOT`.
